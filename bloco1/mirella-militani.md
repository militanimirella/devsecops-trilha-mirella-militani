&#x20;Pergunta:

Escreva uma breve explicação (COM SUAS PALAVRAS) sobre o que são SAST, DAST, SCA e como cada um deles ajuda no desenvolvimento seguro.



&#x20;Resposta:

\- SAST (Static Application Security Testing): É a análise estática que varre o próprio código-fonte em busca de falhas antes de a aplicação rodar, de dentro para fora. Ajuda a identificar vulnerabilidades, más práticas e dados sensíveis expostos logo no início do desenvolvimento, tornando o conserto mais rápido e barato.

\- DAST (Dynamic Application Security Testing): É a análise dinâmica que testa a aplicação enquanto ela está em execução, de fora para dentro. Ajuda simulando ataques reais no sistema rodando para encontrar falhas de autenticação, URLs vulneráveis e brechas de configuração no ambiente.

\- SCA (Software Composition Analysis): É a análise da composição do software, focada nas bibliotecas e dependências de terceiros que o projeto importa. Ajuda a garantir que o código não utilize pacotes desatualizados ou com vulnerabilidades conhecidas (CVEs)
